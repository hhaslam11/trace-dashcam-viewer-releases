# Trace Dashcam Viewer — Releases

This repository hosts release artifacts and the Sparkle auto-update feed for [Trace Dashcam Viewer](https://tracecam.app).

- **DMGs** are attached as assets on each [GitHub Release](https://github.com/hhaslam11/trace-dashcam-viewer-releases/releases).
- **`appcast.xml`** is the Sparkle update feed the app polls. It's regenerated by the `release.sh` script in the [main repo](https://github.com/hhaslam11/sentry-map) on every release.

## Stable download URL

The marketing site links to:

```
https://github.com/hhaslam11/trace-dashcam-viewer-releases/releases/latest/download/Trace-Dashcam-Viewer.dmg
```

Each release uploads two DMGs:
- `Trace-Dashcam-Viewer-<version>.dmg` — versioned, referenced by `appcast.xml`.
- `Trace-Dashcam-Viewer.dmg` — stable filename for the latest-release redirect above.

## Source code

The app's source lives in the main repo. This repo only carries release artifacts.
